Règles

  • Primaire : gradient 135°, #041632 → #1B2B48, texte blanc.
  • H1 light : #041632. H1 dark : #D7E2FF pour rester lisible.
  • Rouge : erreurs et actions destructives. Orange : avertissements. Vert : succès.
  • Cibles tactiles ≥44 px ; focus visible ; labels et icônes accompagnent les couleurs.
  • Mobile : navigation inférieure, action Ajouter centrale. Web : barre latérale.
  • FR et EN : même structure et mêmes permissions.

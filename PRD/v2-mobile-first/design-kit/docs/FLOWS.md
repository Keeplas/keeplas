# User flows

## Mobile sign-up

M08-1 Welcome → M01-1 Phone number → M01-2 WhatsApp code → M01-3 Passkey → M01-4 Vault → M01-5 Contacts (optional) → M01-6 Done → M08-5 Home

## Desktop visitor without an account

W04-1 Sign in → Get the app (to design) → M08-1 Welcome on the phone → M01-1 → M01-6 Sign-up → W04-2 QR on the computer → M03-4 Scan + M03-5 Approve → W04-3 Dashboard

## Web sign-in with the phone

W04-1 Sign in → W04-2 QR → M03-4 Scan (mobile) → M03-5 Approve + Face ID → M03-6 Browser connected → W04-3 Dashboard

## Add an item

M08-5 Home (+) → M07-1 Add sheet → M07-2 or M07-3 Capture → M07-4 Securing → M07-5 Details

## Invite a person

M06-1 People → M06-2 Add → (recipient) M06-5 Invitation → M06-3 Contact list

## Share a folder

M07-5 or folder → M06-4 Share → M06-6 Access management → (recipient) M03-1 / M03-2 / M03-3

## Recover access through contacts

M08-6 Lost access? → M02-1 Methods → M02-2 Request in progress → (contact) M02-3 Approve → M02-4 Vault restored

## Life check

Notification → M02-5 / M02-6 or W05-3 / W05-4 → Back to previous screen

## New device alert

Notification → M08-4 Alert → It was me: close → It wasn't me: W04-6 / M08-3 Devices and revocation
